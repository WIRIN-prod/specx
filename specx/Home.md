# specx

The SpecX record for this project. The user decides; agents execute. Read [RULES.md](RULES.md) first.

- [Specs](specs/README.md): what the project does and must do, as an area/component/feature hierarchy
- [Decisions](decisions/README.md): every choice the user has made or still needs to make
- [Tasks](tasks/TASKS.md): the single task list
- [Reviews](reviews/README.md): review reports

## Commands

- `/specx:plan`: write specs for existing code or new work, collect decisions, and break approved specs into tasks
- `/specx:execute`: build approved tasks, each in its own worktree, then test, run a security review, and merge by pull request after approval
- `/specx:review`: review code, with or without specs, for gaps, flaws, and missing use cases
