# Knowledge proposals

Proposals are review artifacts, not accepted project knowledge. Keep them in this directory with stable IDs. A proposal must enumerate exact additions, modifications, and removals; cite evidence; distinguish observed facts from desired behavior; list unresolved questions and impact; and offer options without selecting for the user.

After explicit approval, record who/when/what was approved in `specx/knowledge/decisions/README.md`, then update the canonical knowledge files. Approval applies only to the exact reviewed proposal revision. Any material change requires renewed approval.
