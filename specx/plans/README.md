# Approved work plans

Store one plan per goal with phases, task IDs, dependencies, acceptance criteria, affected knowledge/components, risk, and proposed agent capability with rationale. The agent may recommend who or what capability fits a task, but the user approves the plan and any assignment policy. A plan is executable only after explicit user approval. Preserve completed work and update its status in Markdown.

Use [PLAN-TEMPLATE.md](PLAN-TEMPLATE.md). A suggested capability and fit score are recommendations, not delegated authority. Base them on task risk, ambiguity, architectural impact, scope size, and required judgment; explain the score so the user can revise it.
