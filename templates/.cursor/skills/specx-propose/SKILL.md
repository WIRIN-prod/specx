# specX propose

Follow `.specx/commands/propose.md` in full.

## Quick checklist

1. `specx status` + search existing `specx/specs/`
2. Create `specx/changes/<kebab-name>/proposal.md`
3. Fill **Capabilities** (new + modified domains) — drives all later artifacts
4. Present to human before `/specx:spec`

## Name rules

kebab-case: `add-oauth-login`, `payment-refund-flow`
