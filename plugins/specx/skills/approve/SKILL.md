# Record a user approval

1. Confirm the user explicitly approved this proposal and identify its exact revision/content. Silence, a request to continue, or approval of a different revision is not approval.
2. If a question is unanswered or the proposal changed materially, leave it pending and ask the user. Do not infer a decision.
3. Record the user's decision, date, proposal revision, and scope in the proposal and a decision record. Preserve declined alternatives and rationale when provided.
4. Apply only approved changes to canonical knowledge. Mark facts user-confirmed only to the extent explicitly confirmed; source-derived claims retain citations and source-verified status.
5. Do not treat approval of project knowledge as approval of implementation code or a broader plan.
6. Update coverage and checkpoint, then show the user the records changed.
