# Specs

Specs are a hierarchy: `<area>/<component>/<feature>.md`. Areas and components have a `README.md` overview. IDs mirror the path, for example `IAM`, `IAM.AUTH`, `IAM.AUTH.LOGIN`. The file format is in the `plan` skill.

Only specs with `status: approved` can be built.
